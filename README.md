# AI人像完整技能包

以**锁住真人身份**为核心，并提供 AI 写真 / 杂志封面 / 人像海报这一种调用场景。

核心是**身份扫描路径控制器**：首轮先用 P0/P1/P2 分级身份基线和全部有效真人参考图建立整体身份，再用本地检测与身份模型判断候选是否仍是本人；第二轮起执行“修一个—验一个”。未达标不移动，局部改善但整体身份退化就回退历史最佳图。它不绑定 Gemini，也不声称直接控制生图模型内部 attention。

第二阶段已加入可选的468点稠密建议层：模型存在且观测可靠时补充脸型、眼区、鼻部和条件性嘴部修正；模型缺失时自动退回五点机制。未经真实样本校准的稠密指标不会单独把候选判成“不是本人”。

## 快速开始（3 步）

1. **双击 `初始化.command`（macOS）/ `初始化.bat`（Windows）** —— 自动检查 Python、生成配置模板、装依赖、补模型。
2. **让 AI 助手读「首次配置问卷.md」** —— 它会像客服一样逐题问你（用没用过生图、有没有 key、选哪个模型），每题先告诉你代价再让你选。纯新手也能配好。
3. **按问卷结论开始出图**。

> 你的 AI 助手叫什么不重要（Claude Code / Codex / 其他 agent 都行）——把本文件夹路径告诉它，让它读 `ai人像摄影技能包/SKILL.md` 开始。

## 进阶：自动评分重 roll

`人脸自动相似替换/` 是正式验收入口：用户可直接搜索并选择内置摄影风格，此时可用图1加最多 7 张同一人辅助真人图走 portrait 身份路径；也可上传图2精确参考动作与构图，此时走 replacement，图2先被超粗马赛克遮脸并启用串脸检查。替换模式仍固定只发送图1和已遮脸图2。两种模式都先做画面完整性检查，再用 SFace / ArcFace / AdaFace 和注意力状态机评分，一次只修一个关键部位。

- 用法：双击 `人脸自动相似替换/启动.command`（macOS）或 `启动.bat`（Windows），界面里选"执行 AI"（Codex / Claude Code / 自定义）。
- 需要：机器上有 **Codex CLI 或 Claude Code CLI**（二选一）。

## 效果一致性说明（重要）

- **模型 + 规则**：规则随源码提供。首次初始化从上游下载约 192 MiB 的运行模型，核对 SHA-256 后在本地加载。人物档案和真人照片由使用者自行保管。新使用者第一次仍需建立 provisional 档案并人工确认，不能承诺首次效果与作者个人资料库 100% 一致。
- **生图 API / 模型**：由使用者自己填（config.json）。用问卷推荐的组合（vision=gemini-2.5-pro，生图 nano-banana-2 或 gpt-image-2）效果最稳；换别的模型效果会有差异。
- 相同接口和模型只能减少变量，不能保证首次就复现作者个人资料库的效果；身份档案是否经过真人验证、参考图是否完整同样关键。

## 安全提醒

- `ai人像摄影技能包/config.json` 里是**你自己的 API 密钥**，**不要发给别人、不要传上网**。仓库仅提供 `config.example.json`，初始化会生成本机配置。
- 系统提示词模式会发送图1、你明确添加的辅助真人参考（最多 7 张）与本地压缩后的风格文本；图2模式固定只发送图1和已遮脸图2。图2原图只在本机做遮脸与本地评分，**不会传给生图工具**。上传前请确认你有权使用照片，并阅读所选服务的隐私规则。
- 自动重 roll 默认会在完成后清理任务内的图1复制件、身份向量、遮脸参考和候选图，仅保留最终图、报告和日志；**不会改动你的原照片**。需要保留中间结果时可在界面中取消勾选。
