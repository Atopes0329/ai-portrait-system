# AI 人像锁脸生成

一个以本地 ONNX 身份评分和注意力闭环为核心的人像生成工具。风格既可以来自内置摄影提示词，也可以来自经过遮脸处理的参考图。

## 项目结构

```
人脸自动相似替换/
├── README.md              # 详细使用说明
├── requirements.txt       # Python 依赖
├── download_models.py     # 模型下载脚本
├── verify_models.py       # 模型校验脚本
├── 启动.command            # macOS 启动入口
├── app.py                 # GUI 主程序
├── face_guard.py          # 核心遮脸与评分逻辑
├── style_library.py       # 摄影风格去身份压缩与兼容性分级
├── identity_ensemble.py   # 多模型身份验证
├── model_bakeoff.py       # 模型对比实验工具
├── 提示词模板.txt          # 生图提示词模板
├── AGENTS.md              # Agent 自动重 roll 规则
└── models/                # 模型目录（需下载）
    ├── README.md          # 模型来源与 SHA-256
    └── *.onnx             # 4 个运行模型及可选 Face Mesh
```

## 快速开始

### 1. 安装依赖

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

### 2. 下载模型

自动下载核心模型（约 192 MiB）：

```bash
.venv/bin/python download_models.py
```

或手动下载后放入 `models/` 目录，详见 `README.md`。

### 3. 启动程序

- **macOS**: 双击 `启动.command`
- **命令行**: `.venv/bin/python app.py`

### 4. 使用流程

1. 选择图片1：本人清晰正脸
2. 从系统摄影风格中搜索选择，或上传图片2参考动作、服饰和构图
3. 调整身份严格度（默认 0.90）
4. 点击“开始锁脸生成”

所有输出保存在 `任务输出/日期时间_任务名/` 目录。

## 核心功能

- **隐私保护遮脸**: 自动对参考图（图片2）进行马赛克处理，确保不泄露原始人脸
- **系统提示词锁风格**: 本地压缩内置风格，只发送最多 8 个去身份画面约束，不需要图片2
- **多模型身份验证**: 使用 SFace、ArcFace、AdaFace 三重验证确保身份相似度
- **自动重 roll**: 未达标时自动重试，最多可设置重试次数
- **详细评分报告**: 每轮生成独立评分 JSON，记录三模型分数与串脸检查

## 安全设计

- 图片2原图路径不写入任何日志，不传给生图工具
- 图片2固定使用超粗马赛克，保留动作但彻底遮挡人脸
- 所有人脸特征仅在本机提取，不上传
- 多模型交叉验证防止误判
- 自动停止机制避免无限消耗额度
