# 快速开始指南

## 一、解压

将 `人脸自动相似替换.tar.gz` 解压到任意目录：

```bash
tar -xzf 人脸自动相似替换.tar.gz
cd 人脸自动相似替换
```

或在 macOS/Windows 图形界面中双击解压。

## 二、安装依赖

需要 Python 3.8 或更高版本。本项目在项目虚拟环境 `.venv` 中运行，不污染系统 Python。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

依赖包括：
- numpy >= 1.24
- opencv-contrib-python >= 4.10
- onnxruntime >= 1.19

## 三、下载模型

运行自动下载脚本（推荐）：

```bash
.venv/bin/python download_models.py
```

脚本会自动下载 3 个核心模型（约 100 MB）：
- face_detection_yunet_2023mar.onnx
- face_recognition_sface_2021dec.onnx
- arcfaceresnet100-11-int8.onnx

**注意**：AdaFace 模型（92 MB）的官方链接已失效，需要手动获取。程序在没有该模型时仍可运行，但身份验证准确性会降低。

验证模型完整性：

```bash
.venv/bin/python verify_models.py
```

## 四、启动程序

### macOS
双击 `启动.command`

### Windows
双击 `启动.bat`

### 命令行（所有系统）
```bash
.venv/bin/python app.py        # macOS / Linux
.venv\Scripts\python.exe app.py  # Windows
```

## 五、使用

1. **选择图片1**：本人清晰正脸照片（作为身份来源）
2. **选择图片2**：参考照片，用于动作、服饰、构图、光线（人脸会被自动遮挡）
3. **调整参数**：
   - 身份严格度：0.90（默认，推荐）
   - 最多重 roll：6 次（默认）
4. **点击开始**：程序自动处理并生成结果

## 常见问题

### Q: 提示缺少 cv2 模块
A: 运行 `.venv/bin/pip install opencv-contrib-python`

### Q: 下载模型失败
A: 检查网络连接，或参考 `README.md` 中的手动下载链接

### Q: 程序运行但无响应
A: 检查是否已登录 Codex 账号，程序依赖其生图能力

### Q: 身份相似度不够高
A:
1. 确保图片1是清晰正脸照
2. 提高身份严格度到 0.95
3. 增加最多重 roll 次数
4. 下载 AdaFace 模型以启用三重验证

### Q: 想用在 AI Agent 中
A: 查看 `AGENTS.md` 了解自动化调用规则

## 进阶使用

### 命令行模式

建立 portrait 纯人像任务：
```bash
.venv/bin/python face_guard.py prepare \
  --source "图片1.jpg" \
  --reference "辅助真人1.jpg" \
  --prompt "$(cat 提示词模板.txt)" \
  --threshold 0.90 \
  --max-rolls 6
```

需要图2时再加 `--style "图片2.jpg"`，切换为 replacement 模式并自动遮脸。

需要使用内置摄影提示词时改加 `--style-preset "风格文件.md"`。系统会保持 portrait 身份路径，只发送图1，并把原始风格文档压缩成最多 8 个非身份画面要素；`--style` 与 `--style-preset` 不能同时使用。

给候选图评分：
```bash
.venv/bin/python face_guard.py score \
  --job "任务输出/20260812_143000_我的写真/job.json" \
  --candidate "候选.png"
```

完成任务：
```bash
.venv/bin/python face_guard.py finalize \
  --job "任务输出/20260812_143000_我的写真/job.json"
```
