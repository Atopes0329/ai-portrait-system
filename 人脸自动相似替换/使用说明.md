# AI 人像锁脸生成

系统支持两种风格入口：系统摄影提示词不需要图2，走 `portrait` 身份路径；上传风格参考图则走 `replacement`，保留图1身份并使用图2动作、服饰、构图和滤镜。双击 `启动.command`（macOS）或 `启动.bat`（Windows）即可使用。

## 使用流程

1. 选择图片1：本人清晰正脸。程序会记住该路径，以后可以不重复选择。
2. 在“系统摄影风格”和“上传风格参考图”中二选一。系统风格默认只显示锁脸优先项目，可搜索，也可取消过滤查看受限风格。
3. 调整身份严格度和最多重 roll 次数；默认是严格的 `0.90` 与最多 `6` 次。
4. 点击“开始锁脸生成”。

每个任务都保存在 `任务输出/日期时间_任务名/`：

- `图片2_已彻底遮脸.png`：真正送入生图工具的图2；
- `generation_reference_images`：portrait 模式正式生图使用的全部真人参考图；
- `图片2_遮罩审计图.png`：白色区域表示已遮挡范围；
- `参考图分析.json`：从已马赛克图2提取的动作、服装、构图、光线、色调、家具和背景结构；不包含图2人脸身份；
- `candidates/roll_NN.png`：各轮全分辨率候选；
- `candidates/*.score.json`：每轮 SFace、ArcFace、AdaFace 独立分数与图2串脸检查；
- `最终结果.png`：达标图或最大轮数内的最高分图；
- `最终报告.json`：是否达标及完整分数。

系统风格模式额外保存 `系统摄影风格.json`，只含最多 8 个去身份、去文字的画面要素；不会生成图片2文件，也不会显示无意义的图2相似度。

## 安全设计

- 图2固定使用约 4×N 的超粗马赛克，保留头部朝向和手脸位置。马赛克后如果检测器仍能识别人脸，程序只会继续加粗马赛克；绝不会退回纯色或不透明遮挡。最强马赛克仍无法消除检测时，任务会安全停止。
- 系统摄影风格模式只发送图1和精简文本；原始 Markdown 不上传，样例人物身份、发型、眼镜和文字排版会被剔除。
- 图2原图路径不会写入 `job.json`，不会传给 Codex 或生图工具。
- 图1与图2原脸只在本机转成数字特征。原图2不会保存进任务目录，也不会交给生图工具。
- 身份评分同时记录 SFace、ArcFace、AdaFace。三者分值尺度不同，因此不做虚假的简单平均：SFace 使用严格门槛，ArcFace 与 AdaFace 用来拦截两个模型都判定明显不符的异常候选。
- 候选必须同时满足：图1身份达到门槛；没有被两个辅助模型共同否定；没有越过图2串脸警戒；人脸尺寸足够评分。
- 身份分只判断“像不像本人”。动作、服饰、构图、滤镜、自然度仍由自动流程做第二层视觉复核。
- 达到最多轮数后一定停止，避免无限消耗生图额度。

## 命令行（可选）

建立 portrait 纯人像任务：

```bash
.venv/bin/python face_guard.py prepare \
  --source "/路径/图片1.jpg" \
  --reference "/路径/辅助真人1.jpg" \
  --reference "/路径/辅助真人2.jpg" \
  --prompt "$(cat 提示词模板.txt)" \
  --threshold 0.90 --max-rolls 6
```

使用系统摄影风格时增加 `--style-preset "风格文件.md"`。该文件必须位于相邻 `ai人像摄影技能包/ai人像摄影提示词/`，并且不能与 `--style` 同时使用。

需要图2动作/服装参考时，再加 `--style "/路径/图片2.jpg"`，系统切换为 replacement 模式并自动遮脸。

给一张候选图评分：

```bash
.venv/bin/python face_guard.py score --job "/路径/job.json" --candidate "/路径/候选.png"
```

自动推进单重点闭环并生成下一轮干净提示词：

```bash
.venv/bin/python face_guard.py iterate --job "/路径/job.json" --candidate "/路径/候选.png" --identity-anchor-file "/路径/identity_锁脸段.txt"
```

本程序不会覆盖或修改图片1、图片2原文件。
