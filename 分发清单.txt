分发清单
====================================
把整个「AI人像完整技能包」文件夹发给别人前，照下面检查。

一、必须有的文件
- 初始化.command（macOS）/ 初始化.bat（Windows）/ setup.py（跨平台，核心）
- 首次配置问卷.md
- AGENTS.md / README.md / SYSTEM.md
- ai人像摄影技能包/（SKILL.md、使用教程.txt、config.example.json、scripts/、ai人像摄影提示词/ 87个风格 + 1个身份说明文档、示例/）
- 人脸自动相似替换/（代码、文档、启动.command + 启动.bat、style_library.py、identity_lock/、vision_judges/、calibrate_thresholds.py、models/README.md 和 4 个运行模型的下载与校验脚本）

二、绝对不能发的
- ai人像摄影技能包/config.json     ← 含你的 API 密钥，发出去等于把钥匙送人
- 人脸自动相似替换/.venv           ← 本地环境，对方机器用不了
- 人脸自动相似替换/任务输出         ← 你的出图记录
- 人脸自动相似替换/本地设置.json     ← 你的图片路径记忆
- ai人像摄影技能包/特征库/*          ← 人物文字档案与 validated sidecar
- ai人像摄影技能包/出图/*            ← 候选图、黄金成片与评分文件
- ai人像摄影技能包/示例/*            ← 本机示例成片也按测试数据排除
- 根目录迭代进化.md 的个人内容        ← 分发时必须替换为空白模板
- tasks/                              ← 本机开发计划与诊断记录
- 任何个人照片 / 私人数据
- GitHub 仓库中的 ONNX 权重（由初始化脚本从各自上游下载）

三、发送前自查
1. 「ai人像摄影技能包/config.json」必须不存在（对方双击初始化.command 会自动生成新模板）
2. 确认没有 .venv / 任务输出 / 本地设置.json，且 特征库/ 与 出图/ 为空
3. 在验证副本中初始化下载 4 个运行模型，运行 verify_models.py 检查 SHA-256，确认 Git 暂存区排除了权重文件
4. 运行离线测试并确认全部通过；风格库审计必须确认没有样例人物身份词进入精简风格段；Face Mesh 缺失只影响可选稠密建议层，不影响运行模型校验
5. 确认分发版包含提示词预算审计、画面完整性门、重复人脸框合并和多真人参考入口；替换模式仍必须固定只外发图1与已遮脸图2

四、对方需要准备什么
- 生图方式二选一：
  A 手动粘平台（即梦 / Midjourney / 可灵）——零门槛，不用注册
  B 一个 API key——去 AI 中转站或官方平台注册
- 若要用「人脸自动相似替换」的自动重 roll：机器上有 Codex CLI 或 Claude Code CLI（二选一）

五、如何重新打包（改过源以后）
推荐运行：`python3 package_clean.py "/一个尚不存在的新目录"`。脚本默认拒绝覆盖已有目录，自动清空人物档案/出图并把迭代日志换成空白模板，最后生成 `DISTRIBUTION_AUDIT.json`。桌面旧打包脚本若继续使用，也必须执行相同排除规则。
