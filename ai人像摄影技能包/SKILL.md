# AI 人像摄影技能包

**一句话原理**：首轮用已验证的 P0/P1/P2 身份基线和全部有效真人参考图把整体身份立住；评分后才进入“固定基线 + 当前一个修正重点”的闭环。P3 不占身份预算，历轮修正不累积。

---

## 一、首次使用 — 先回答配置问题（只需要做一次）

**先检查本文件夹里有没有 `config.json`。有 → 跳过本节，直接看「二、完整工作流」。没有 → 按根目录 `../首次配置问卷.md` 的问卷流程，逐题询问使用者并配置。**

问卷完全自包含：覆盖有/无 API、能不能看图、模型选择、纯新手零门槛路径——**每题先预警"选这个的代价"，再让使用者选**。答完把结果写进 `config.json`，念一遍确认无误再开始干活。

下面 4 个问题是问卷要写入的字段映射，供参考：

| # | 问题 | 写入字段 | 说明 |
|---|------|---------|------|
| 1 | **你的 agent（当前这个 AI）自己能看图吗？**（能直接看懂参考图里的人脸吗？） | `vision.agent_can_see` | 能 → 填 `true`，特征建模直接让 agent 看参考图，不用外部 vision 接口；不能 → 填 `false`，必须有外部能看图的 API |
| 2 | **特征建模（看参考图）用哪个能看图的模型/服务？** 提供 host、key、模型名 | `vision.host` `vision.key` `vision.model` | 任一套 OpenAI 兼容的多模态接口都行（Gemini / GPT / Claude / 各家中转）。如果问题 1 答了「能看图」且不想额外接 API，这三项可留空 |
| 3 | **生图怎么跑？** 直接调 API（自动出图）还是只导出提示词自己手动粘平台？ | `generate.mode` | `chat` = 参考图直接进对话（nano-banana 型模型，锁脸最强，推荐）；`draw` = 异步 draw 接口（gpt-image 型）；`export` = 不联网，只把提示词导出成文件，自己粘到任意平台 |
| 4 | **生图用哪个服务/模型？** 提供 host、key、模型名；`chat` 模式用 `model`，`draw` 模式用 `draw_model`；图片存哪 | `generate.host` `generate.key` `generate.model` `generate.draw_model` `generate.out_dir` | 生图服务和 vision 可以是**同一家，也可以不同**（config 分开就是为了「vision 结果返回给谁」可配） |

**配置示例**（`config.example.json` 已含模板）：
```json
{
  "vision": {
    "agent_can_see": false,
    "host": "https://中转站或官方API地址",
    "key": "sk-xxx",
    "model": "gemini-2.5-pro"
  },
  "generate": {
    "mode": "chat",
    "host": "https://中转站或官方API地址",
    "key": "sk-xxx",
    "model": "nano-banana-2",
    "draw_model": "gpt-image-2",
    "out_dir": "出图"
  }
}
```

**中途要换模型/换平台？** 只改 `config.json` 对应字段，脚本和流程都不用动。`vision` 和 `generate` 可以分别指向不同服务。

⚠️ config.json 里有 API 密钥，**不要把这个文件发给别人、不要提交到任何公开仓库**。

## 二、完整工作流（每一次正式出图都走这 8 步）

### 第 1 步：整理参考图
先读系统根目录 `../迭代进化.md` 和人物档案状态。拿到照片后，挑出 **1 张正面、脸清晰的作「基准图」**，再带 2~8 张不同角度的作辅助。第一张永远是锁脸基准，其余只做多角度确认，不重新定义脸。
- 已有档案先运行 `python3 scripts/profile_guard.py check --profile 特征库/<人物>_特征.md`。
- `validated` 且哈希完整 → 直接复用，不重新建模；`provisional` / `untracked` → 只能作为候选，不得声称已验证。
- 已确认相似的 AI 成片只能登记为 `regression_only`，禁止混进真人参考图。
- 照片是 heic / 微信图先转成 jpg / png。
- 用 `file 图片路径` 确认格式没问题再往下走。

### 第 2 步：特征建模 —— 把图交给能看图的模型，翻译成文字
这是**铁律：每一批新人物，出第一张图之前必须先做一次特征建模。跳过 = 赌模型零样本理解参考图，大概率不像。**

- 如果 `config.vision.agent_can_see = true`（agent 自己能看图）：**直接让 agent 盯着参考图，逐条描述下面 10 项**，输出作为特征文字。
- 否则跑外部 vision 脚本（**必须加 `--out` 把结果存成文件**，下一步直接读文件，不用手动抄）：
  ```bash
  python3 scripts/vision.py "参考图.jpg" ["更多参考图.jpg"] --out 特征.md
  ```
  `特征.md` 会包含：10 项完整内部档案 + 正式首轮使用的「基线锁脸段成品」+ 默认负面段，并写入 provisional 状态与参考图哈希。基线只含 P0/P1/P2，P3 不进入身份提示。
  - 目标文件已存在时默认拒绝覆盖；只有 provisional 档案可显式加 `--replace-provisional`。validated 档案只能另存候选，等待真人重新确认。
  - **出图是侧脸/俯仰角度**：加 `--angle 45度侧脸|90度侧脸|斜上方|斜下方`，锁脸段按该角度写，减少角度跑偏。
  - **自动能力**：漏项自动自检补全；主模型挂了自动降级重试；大图自动压缩。都不用你管。

**建模必须覆盖这 10 项**，每项尽量具体、中性客观、不要评价美丑：
1. 性别与大致年龄
2. 整体脸型与骨相（长宽比、方圆/鹅蛋/瓜子、额头、颧骨、下颌角、下巴形状，有无婴儿肥）
3. 眉毛（粗细、浓淡、形状、走向、眉峰）
4. 眼睛（大小、单双、眼型、眼距、卧蚕、眼神）
5. 鼻子（鼻梁高低、鼻头形状、鼻翼宽窄）
6. 嘴唇（厚薄、唇形、嘴角）
7. 发型与发色（长度、卷直、纹理、刘海）
8. 是否戴眼镜及眼镜样式
9. 穿着、场景、光线、整体氛围
10. 左右脸不对称、黑痣等可辨识细节

### 第 3 步：拼「分级三段式首轮提示词」
**优先从 validated 档案读取「基线锁脸段成品」；新人物暂用本次 provisional 基线生成待验证首张候选。首轮不得用任意120字摘要替换它。** provisional 结果不能覆盖旧 validated 档案，也不能在真人确认前晋级。完整10项档案只供内部理解；正式提示词固定三段：

1. **身份基线**（必须开头）：使用经验证的 P0 核心空间关系 + P1 眼鼻 + 稳定 P2 外显特征；省略 P3。
   - 若造型要动发型，在画面段写纹理变化，不改本人发型轮廓。
2. **画面段**：风格 + 具体画面描述（场景 / 服装 / 构图 / 光线 / 色调 / 氛围），专业摄影与排版术语用英文点缀。
3. **负面段**（结尾）：取 `特征.md` 里的默认负面段，再按风格补专属负面（西装图加「不要西装结构变形」，马术图加「不要马脸变形、不要缰绳错乱」等）。

### 第 4 步：先建立正式评分任务

纯人像任务没有图2，使用 portrait 模式；`--reference` 把其余真人照片全部登记进去：

```bash
cd ../人脸自动相似替换
.venv/bin/python face_guard.py prepare \
  --source "基准图.jpg" \
  --reference "辅助图1.jpg" --reference "辅助图2.jpg" \
  --prompt-file "../ai人像摄影技能包/首轮提示词.txt" \
  --name "人物_风格"
```

返回结果中的 `job_file`、`generation_reference_images` 和 `session_dir` 是后续唯一任务记录。风格来源有两种，不能同时使用：

- 内置摄影提示词：加 `--style-preset "风格文件.md"`。系统从 `ai人像摄影提示词/` 读取后，在本地剔除样例人物身份、发型、眼镜和文字要求，只把最多 8 个画面要素加入提示词；身份路径仍是 portrait，不增加第二张人物图。
- 图2风格人物图：加 `--style "图2.jpg"` 进入 replacement；只有该模式启用图2遮脸和串脸门。

禁止自行把整篇风格 Markdown 复制进三段式提示词。小比例人物、背影、群像、倒影、严重遮挡或动漫风属于锁脸受限风格，必须先改善脸部可观测性才能验收。

### 第 5 步：首轮生图
按 `generate.mode` 对应：
- `chat`（推荐，锁脸最强）：
  ```bash
  python3 scripts/generate.py chat --prompt-file "<session>/提示词.txt" \
    --ref "基准图.jpg" --ref "辅助图1.jpg" --ref "辅助图2.jpg" \
    --out "<session>/candidates/roll_01"
  ```
- `draw`：
  ```bash
  python3 scripts/generate.py draw "三段式提示词" --ref "基准图.jpg"
  ```
- `export`（手动粘平台兜底）：
  ```bash
  python3 scripts/generate.py export "三段式提示词" --ref "基准图.jpg" --out 锁脸提示词.md
  ```

直接调用 `generate.py` 但没有 `job.json`、候选评分和状态文件，只算手动预览，不算系统正式试跑。

### 第 6 步：给使用者看 —— 不许假装看过
把生成的图片**打开给使用者看**，等反馈。AI 自己不能代替使用者判断像不像。

### 第 7 步：评分与单重点迭代
- 首张候选必须立即交给相邻的 `人脸自动相似替换/face_guard.py iterate`；它会保存历史最佳图、锁定一个当前重点、检查整体身份退化并输出 `下一轮提示词.txt`：
  ```bash
  .venv/bin/python face_guard.py iterate --job "<session>/job.json" \
    --candidate "<session>/candidates/roll_01.png" \
    --identity-anchor-file "../ai人像摄影技能包/特征库/<人物>_特征.md"
  ```
- 未达当前重点门槛时继续同一重点；达标后才切换。整体身份或身份来源失守时，立即暂停局部修正。
- 生图脚本使用 `--prompt-file 下一轮提示词.txt`，禁止在上一轮文本后追加修正历史。
- `vision.py --fix` 只可输出 advisory 单重点建议，不得用它生成完整十项替换段，也不得绕过状态机直接重写身份基线。
- AI视觉评分未经真人样本校准时只作旁观建议；SFace、ArcFace、AdaFace和退化保护仍是硬护栏。
- 达到完成状态后仍让使用者做最终辨认。同一人物的完整特征档案可以复用，但每轮活动指令始终只有一个。

### 第 8 步：人工确认、档案晋级与自我进化
**每次任务，开始读一次、收尾写一次。**

- **任务开始前**：读系统根目录 `../迭代进化.md`——
  - 查「人物特征索引」：这个人已建模过？是 → 直接复用 `特征库/<人物>_特征.md`，**不重新建模**。
  - 扫一眼「经验条目」：避开已知的坑，复用已验证有效的写法。
- **任务收尾后**：按 `../迭代进化.md` 的「经验条目」格式，在顶部追加一条（做了什么 / 效果 / 哪些有效 / 教训 / 下次改进）。经验要具体可复用，不要空话。
- **新人物**：特征文件存到 `特征库/<人物>_特征.md`，并加入迭代日志的人物特征索引。
- 使用者确认真正像后，可运行 `profile_guard.py validate` 把档案从 provisional 晋级为 validated；`--golden-output` 登记的成片仅作回归标尺。

## 三、注意力优先级（核心判断标准）

**内部可以测量很多，外部每轮只说一个。** 依据整体身份优先、任务驱动扫描和局部诊断原则分配修正顺序。

| 优先级 | 部位 | 描述密度 | 负面段 |
|---|---|---|---|
| **P0 核心空间关系** | 眼距、脸型长宽比、眼-鼻-嘴空间位置 | 最细、量化精确 | 加防漂移 |
| **P1 眼睛优先** | 眼睛、鼻子 | 详细 | 加防漂移 |
| **P2 结构外显** | 眉毛、嘴唇、发型、眼镜 | 适中精确 | 按需加 |
| **P3 低优先级** | 皮肤、痣、胡青、情绪、穿着 | 一句话或省略 | **一律不加** |

**三条铁律**：
1. 首轮常驻身份基线保留 P0/P1 和稳定 P2；局部活动预算从第二轮起一次只给一个最高优先级特征。
2. 负面段只对 P0/P1/P2 加防漂移，**P3 一律不加**（写了反而引导模型注意、放大失真——黑痣/皮肤质感就是这么变假的）。
3. 与机器评分联动：当前重点低于门槛不得切换；局部变好但整体身份下降时回退历史最佳图；P3不得触发自动追修。

## 四、避坑清单

- **中文文字必乱码**：AI 生图写中文（标题、标语）不可靠。生图 prompt 一律要求英文排版或留空（no text），中文文字后期在排版/HTML 层叠加。
- **风格参考**：如果使用者给了一张想要的风格图/模板，**别直接丢给生图模型说"照着来"**。先分析配色比例、版式分区、光线氛围，翻译成具体参数写进画面段。
- **风格适配三查**：使用者给风格模板时，检查三处是否与本人冲突，冲突按本人适配——① 性别词（模板写男而对象是女，反之亦然）；② 发型要求（模板要湿发背头/寸头但本人不是，保留本人发型轮廓，只取「湿润纹理」这类可叠加质感）；③ 文字元素（模板里的中文书法/标语，生成时一律留白）。
- **不像的排障顺序**：先查是否误覆盖 validated 档案 → 首轮是否用了 P0/P1/P2 基线 → 是否传入全部登记真人参考图 → 是否实际产生 job/score/state → 再查风格段；最后才考虑模型或接口。
- **余额/额度报错**：接口返回余额不足之类的错误就停下，让使用者去充值，别硬试。

## 五、完整模板参考（验证过的效果范式）

```
基线锁脸段成品：以第一张真人参考照片（X1）为唯一身份来源，保持经验证的 P0 脸型与五官空间关系、P1 眼鼻结构以及稳定的眼镜和发型轮廓。为他生成一张白墙硬闪时尚海报半身肖像：白色衬衫、黑色领带松散下垂、极简纯白背景、巨大人物阴影、硬闪光摄影、高反差影棚灯光、after hours editorial 氛围、轻微胶片颗粒、no text。不要五官变形、不要背景杂乱。
```

（配 `--ref 基准图 --ref 辅助图`。迭代时只增加系统选出的一个当前身份修正点。）
