========================================
  AI 人像摄影技能包 —— 使用教程
  （给完全没接触过的人看的傻瓜版）
========================================

本教程分 5 段：
  一、这个包是干什么的
  二、你需要准备什么
  三、怎么开始用（关键：先回答几个问题）
  四、一次完整的出图流程（跟着做就行）
  五、常见问题


------------------------------------------------------------
一、这个包是干什么的
------------------------------------------------------------

一句话：把你提供的某个人（真人）的照片，生成成这个人本人
的 AI 艺术照 / 写真 / 杂志封面 / 海报，脸不会变成别人。

文件夹里的「示例」目录放了一张成品图（杂志封面风格），
你可以先打开看看最终效果大概长什么样。

它工作的核心只有一件事——「锁脸」：
  先让一个能看图的 AI 把你照片里的人脸特征仔仔细细描述出来，
  再把这些描述 + 你的照片一起交给生图模型，让生成的人长得
  和你照片里是同一个。就这么简单。


------------------------------------------------------------
二、你需要准备什么
------------------------------------------------------------

只需要三样，其他都不用管：

1. 一个「能看图的 AI」或者一个「能看图的接口（API）」
   - 如果你的 AI 助手本身能看懂图片（比如能描述照片里的人长什么样），
     那第一样就满足了，什么都不用买。
   - 如果不行，就去找一个提供"视觉接口"的服务，注册拿一个 key。
     （比如各类 AI 中转站、官方 API 都行，跟本包用的是哪种不冲突）

2. 一个「能生图的模型 / 平台」
   - 任意支持"参考图"功能的生图工具都行：
     * 支持自动调用的 API（推荐，省事）；
     * 或者像即梦、Midjourney、可灵这类网页/App 平台，
       它们一般有"参考图/参考人物"上传入口，也完全能用。

3. 被拍的人的照片（2~8 张都行）
   - 挑一张正面、脸最清楚、最好看的角度当"基准图"，
     其他的当辅助。不用刻意修图，正常手机照片就行。

★ 最省事的组合：用一个支持参考图生图的 API，你只需要一个
   API key，剩下的流程全自动。


------------------------------------------------------------
三、怎么开始用（关键：先回答几个问题）
------------------------------------------------------------

第一步：把整个「ai人像摄影技能包」文件夹给你的 AI。
   - 如果你用的是桌面版 / 网页版 AI：把文件夹路径告诉它，
     或者直接把 SKILL.md 的内容拖给它让它读。
   - 跟它说一句：请你按 SKILL.md 里的「首次使用配置」流程来。

第二步：它会问你 4 个问题，你照实回答：
   1. 你的 AI 自己能看图吗？   → 能 / 不能
   2. 看图的接口地址、key、模型名？  → 没有就留空
   3. 生图用 API 自动调，还是自己粘平台手动出图？ → API / 手动
   4. 生图的接口地址、key、模型名？图片存哪个文件夹？
      → 照它问的填

回答完，它会自动生成一个 config.json 配置文件。
（里面会存你的 key，别把这个文件发给别人。）

以后想换模型/换平台？直接改 config.json 里面对应的内容就行，
其他什么都不用动。

注意：如果你只想手动出图（不填 API），也可以——它会帮你把
一段"锁脸提示词"写好存成文件，你复制到自己的生图平台，
再上传参考图，一样能出。


------------------------------------------------------------
四、一次完整的出图流程（跟着做就行）
------------------------------------------------------------

整个过程你的 AI 会带着你做，你只需要：

1. 把照片文件夹给 AI（比如桌面上的某个文件夹）。
2. 等它问你要哪张当"基准图"（挑正面清晰的）。
3. 它会先"建模"——把你照片里的人脸特征描述出来（这步最关键，
   看起来像在分析人脸，别催它）。建模结果会存成一个"特征"文件，
   后面拼提示词时直接引用，不用你手动抄。
4. 它会拼一段"锁脸提示词"，然后自动生图（或让你手动粘平台）。
5. 生完它会让你看图片，你告诉它像不像：
   - 不像 → 你描述哪里不像（比如"眉毛不一样""显得太老"），
     它改完重新生成。
   - 像 → 可以再让它换风格出更多张。

一句话总结：你负责提供照片 + 说"像/不像"，其他全是 AI 干。


------------------------------------------------------------
五、常见问题
------------------------------------------------------------

Q1: 生成的人不像本人？
A: 先让它确认"特征描述"有没有漏（脸型/眉毛/眼睛/鼻子/嘴唇/
   发型/眼镜/痣，这些项有没有说全）。大多数"不像"都是特征
   描述不完整，不是模型的问题。让它把特征补全重跑。

Q2: 图片上的中文全是乱码？
A: 正常，AI 生图写中文本来就不可靠。让 AI 出图时不要带文字
   （no text），中文标题文字后期单独加。

Q3: 我不想填 API key，能出图吗？
A: 能。选"手动粘平台"模式，AI 帮你把提示词和参考图整理好，
   你自己上传到即梦 / Midjourney / 可灵这类平台的参考图功能。

Q4: 提示我余额不足 / 没额度？
A: 去你用的接口服务后台充值，充完继续就行。

Q5: 这个包会改我自己的照片吗？
A: 不会。它只读取参考照片生成新图，原图不动。


祝出片顺利！有什么卡住的地方，把报错截图丢给你的 AI 就行。
